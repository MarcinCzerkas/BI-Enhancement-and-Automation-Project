# BI Enhancement & Automation

> A professional Excel dashboard solution built for business reporting and process automation.

## 🧩 Project Overview

This repository showcases a **professional Excel-based dashboard** created for a client in April 2025 as part of an operational reporting solution. The dashboard centralizes key project and business metrics and automates repetitive data tasks — helping stakeholders make quick, data-informed decisions. Although the actual Excel file and source data are not provided here due to client privacy, this repo documents the approach, tools, and logic used.  [See more](https://www.linkedin.com/posts/marcin-czerkas-95150727a_project-dashboard-report-activity-7332752402183286784-2iig)

![Dashboard](/Project_042025.png)

## 💡 Objective

The goal was to design a **clear, interactive dashboard** that:

- Visualizes business metrics and KPIs in a single view  
- Automates repetitive processing using Excel’s advanced tools  
- Reduces manual data preparation time  
- Supports non-technical stakeholders with actionable insights  

## 🛠 Tools & Techniques

This project leverages advanced Excel functionalities:

- **Power Query** — for data transformation and ETL automation  
- **Power Pivot & DAX** — for building refined analytical measures  
- **VBA (Visual Basic for Applications)** — for automating workflows and repetitive tasks  
- **PivotTables & Charts** — for interactive visual summaries  
- **Dynamic dashboard design principles** for usability and clarity  

These elements combine to deliver a robust reporting experience with minimal manual intervention.

## 📌 Key Features

While the project assets are not included, the dashboard is conceptually organized around:

- **Automated data ingestion and refresh** (via Power Query & VBA)
- **Multi-table relational data model** (Power Pivot)
- **Custom performance metrics** (DAX formulas)
- **Clean UI panels with filters and drill-downs**
- **Export and reporting automation** for recurring reports
